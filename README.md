# 🚀 Microservices Architecture - Praktikum Sistem Terdistribusi

## 📌 Deskripsi
Project ini merupakan implementasi Microservices Architecture menggunakan Node.js, Express, Docker, dan REST API. Sistem dibagi menjadi beberapa service independen yang saling berkomunikasi.

---

## 🧩 Service
- Auth Service → login user  
- Product Service → data produk  
- Order Service → membuat order & ambil data product  

---

## ⚙️ Teknologi
Node.js, Express.js, Docker, Docker Compose, Axios, Postman
